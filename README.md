# 邵艾伦Alan · 思维操作系统（人物 Skill）

> 「薄肌是一种认知的体现，高智力的体现和自控力的体现，它不是一个单纯的表面的肌肉。」

这是一个可运行的人物 Skill：把 B 站 / X 博主 **邵艾伦Alan**（薄肌理论创始人、口语博主）的思维方式、判断规则和表达风格提炼成一套可调用的框架，用于「用他的视角看问题」。

**不是他本人，不代表他的观点。** 所有内容基于 2026-11-04 前的公开信息。

## 这是什么

不是语录合集，是一套认知操作系统。核心问题是：**他遇到一个新问题时会先看什么、拿什么标准判断、怎么表达。**

包含：
- **6 个心智模型** — 版本论 / 认知显化论 / 动机无关论 / 旧契约失效 / Small Ego / 命名即权力
- **10 条决策启发式** — 「零成本认知升级立刻上车」「一个人抬沙发就走人」等
- **完整的表达 DNA** — 句式、词汇、禁忌词、类比来源、确定性双模态
- **可执行的回答工作流** — 什么时候该先查资料，查哪五样

## 诚实边界（重要）

用之前请知道这几件事：

1. **他的理论大多是旧道理换皮** —— 多运动、多喝水、早睡觉。媒体已明确指出，这里没有装深刻。
2. **大量暴论只见媒体转引，原帖查不到** —— 「薄肌取代美金」「恐龙因为没有薄肌而灭绝」这类，X 上 8–10 月那批帖子在公开时间线里是断的。全部标了「未能核实」，没当原话用。
3. **他的原创论证少于原创命名** —— 4.5 小时对谈里他只占 13% 的字数，结论多半出自孙宇晨嘴里，由他命名。别把他写成思想家。
4. **无法判定他哪些话是真信、哪些是表演** —— 真信 / 半真半演 / 纯反讽，三种都有证据。本 Skill 默认按「半真半演」处理。
5. **「大水理论」不是他的** —— 源头是他的「不说话理论」，由博主「长安二球」提炼。网上普遍挂错名。
6. **他的两性观点争议极大** —— 批评者认为「练薄肌才有 dating 资格」是把女性当奖品。本 Skill 呈现他的框架，但这是他的一面之词。
7. **调研截止 2026-11-04** —— 他三个月换一个赛道，超过三个月就该重新调研。
